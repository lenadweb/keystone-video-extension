# Changelog

## 2.0.0

Prepared for the first public source release. No earlier public release history is claimed.

- Vertical and horizontal perspective correction with per-axis controls and reset.
- Local settings, configurable fine steps and keyboard feedback.
- Video discovery across accessible frames and open shadow roots.
- Popup still-frame preview with a geometric fallback.
- Reversible styles and fullscreen/resize handling.
- Separated types, enums, constants, pure utilities and browser services by runtime context.
- Decomposed video discovery, style management, observers, update scheduling and runtime lifecycle.
- Enforced architectural boundaries, type-only imports and circular-import checks.
- Higher matrix precision for large video sizes.
- Reproducible release packaging, integration tests and CI checks.
- Original Material 3 inspired branding and publication assets.
- Privacy policy, contribution guidance and bundled third-party notices.
