# Security policy

Security fixes target the latest published version. The extension processes page-owned video elements and uses broad host access, so unexpected data access, persistent style changes after disabling and remote-code execution are relevant reports.

For a sensitive vulnerability, use [GitHub private vulnerability reporting](https://github.com/lenadweb/keystone-video-extension/security/advisories/new) if enabled. If unavailable, contact the maintainer at the address in the repository's Git commit metadata. Do not publish an exploit or private browsing data in a public issue.

Include the affected version, reproduction steps, impact and a minimal example without credentials or private video content. There is no guaranteed response time or bug bounty.
