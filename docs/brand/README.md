# Keystone mark

The rounded container preserves the extension's blue identity. Inside it, a projected trapezoid surrounds a squared video frame with a rounded play symbol. Flat tonal layers and a clear silhouette connect it to the Android 15 / Material 3 direction without copying an Android or Google brand asset.

- Master: `src/assets/icons/logo.svg`, 108-unit viewBox.
- Large transparent PNG: `logo-512.png`.
- README PNG: `logo-128.png`.
- Single-color mark: `mark-monochrome.svg`, using `currentColor`.
- Toolbar exports: `public/icons/`, generated by `npm run assets`.
- Editable promo compositions: `promo-small.svg` and `promo-marquee.svg`.

Keep proportions intact. Do not add text, shadows or gradients to the mark. Use the master for new sizes rather than upscaling a toolbar PNG. Original artwork is distributed under the project's MIT license; the font retains its own license.
